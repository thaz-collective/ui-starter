# FieldContainer

A `react-aria-components` `Group` that renders the bordered "field" chrome around a label, input,
and any trailing controls (e.g. stepper buttons), laying them out side by side and reflecting the
field's hover/focus/invalid/disabled state. `Label` and `Input` treat it as their positioning
context for the floating-label and placeholder-fade behavior.

## Import

```tsx
import { FieldContainer } from '#src/components/field-container';
```

`TextField` also re-exports this as `TextField.FieldContainer` for convenience when composing
a text field.

## Usage

`FieldContainer` must be rendered inside a field root (for example `TextField` / `TextField.Root`)
— its border color reacts to that ancestor's `invalid`/`disabled` state automatically.

```tsx
import { useState } from 'react';

import { TextField } from '#src/components/text-field';

function Example() {
  const [value, setValue] = useState('');

  return (
    <TextField
      value={value}
      onChange={setValue}
    >
      <TextField.FieldContainer>
        <TextField.Label>{'Full name'}</TextField.Label>
        <TextField.Input placeholder="Jane Smith" />
      </TextField.FieldContainer>
    </TextField>
  );
}
```

## Behavior

- **Idle**: shows a subtle border around its contents.
- **Hover / focus-within**: border becomes more prominent.
- **Invalid** (`isInvalid` on the field root): takes error styling, including on hover and
  focus-within.
- **Disabled** (`isDisabled` on the field root): the whole container dims and stops responding to
  interaction.
