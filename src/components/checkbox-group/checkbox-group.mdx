# CheckboxGroup

Picks zero or more values from a small list of options, built on top of `react-aria-components`'
`CheckboxGroup`. It reuses the same indicator as [`Checkbox`](/?path=/docs/component-checkbox--docs)
for each option, and adds a shared label, description, validation state, and layout across the
whole set.

## Import

```tsx
import { CheckboxGroup } from '#src/components/checkbox-group';
```

## Composition

`CheckboxGroup` is a compound component. `CheckboxGroup` itself is `CheckboxGroup.Root`, and the
other slots hang off of it:

```
CheckboxGroup (CheckboxGroup.Root)
├── CheckboxGroup.Label (optional)
├── CheckboxGroup.Description (optional)
├── CheckboxGroup.Field (one or more)
│   └── CheckboxGroup.Button
└── CheckboxGroup.FieldError (optional)
```

`CheckboxGroup.Button` is the exact same component as
[`Checkbox.Button`](/?path=/docs/component-checkbox--docs) — the indicator looks and behaves
identically whether it's standing alone or living inside a group.

`CheckboxGroup.Description` and `CheckboxGroup.FieldError` are the same shared components used by
[`TextField`](/?path=/docs/component-textfield--docs) and
[`NumberField`](/?path=/docs/component-numberfield--docs) — they only care about being nested
inside an ancestor carrying the shared field marker, which `CheckboxGroup.Root` provides, so they
work here unmodified.

Every slot must be rendered inside `CheckboxGroup` / `CheckboxGroup.Root` — they read shared
context from React Aria and will not work standalone.

## Usage

```tsx
import { useState } from 'react';

import { CheckboxGroup } from '#src/components/checkbox-group';

function Example() {
  const [value, setValue] = useState(['sms']);

  return (
    <CheckboxGroup
      value={value}
      onChange={setValue}
    >
      <CheckboxGroup.Label>{'Notifications'}</CheckboxGroup.Label>
      <CheckboxGroup.Description>{'Choose how you want to be notified.'}</CheckboxGroup.Description>
      <CheckboxGroup.Field value="email">
        <CheckboxGroup.Button>{'Email'}</CheckboxGroup.Button>
      </CheckboxGroup.Field>
      <CheckboxGroup.Field value="sms">
        <CheckboxGroup.Button>{'SMS'}</CheckboxGroup.Button>
      </CheckboxGroup.Field>
      <CheckboxGroup.Field value="push">
        <CheckboxGroup.Button>{'Push notification'}</CheckboxGroup.Button>
      </CheckboxGroup.Field>
    </CheckboxGroup>
  );
}
```

`value`/`onChange` are required on `CheckboxGroup` / `CheckboxGroup.Root` — it's a controlled
component. `CheckboxGroup.Field` only accepts `value`; selection state comes from the group, not
from an `isSelected`/`onChange` pair on the individual field.

## States

`isRequired`, `isDisabled`, and `isInvalid` are passed to `CheckboxGroup` / `CheckboxGroup.Root` —
they flow down through React Aria context to every slot underneath, which is how
`CheckboxGroup.FieldError` knows to show itself, `CheckboxGroup.Description` knows to hide itself,
and the indicator styling responds automatically across every field in the group.

Adds a `*` after `CheckboxGroup.Label`.

### Error

Set `isInvalid` to turn `CheckboxGroup.Label` and every field's indicator into their error
styling and reveal `CheckboxGroup.FieldError`. Invalid wins over the usual primary color for each

`CheckboxGroup.Root` accepts any other prop supported by React Aria Components'
[`CheckboxGroup`](https://react-spectrum.adobe.com/react-aria/CheckboxGroup.html).

### `CheckboxGroup.Field`

Renders a single checkbox inside the group. Accepts a required `value` identifying it within the
group's selected-value array, plus any other prop `Checkbox.Root` accepts except
`isSelected`/`onChange`.

### `CheckboxGroup.Button`

Renders the indicator box and its `children` as the clickable label — the same component as
`Checkbox.Button`.

### `CheckboxGroup.Label`

Renders text content (`children`) as the group's label; styling responds automatically to the
group's disabled state.

### `CheckboxGroup.Description`, `CheckboxGroup.FieldError`

Shared with `TextField`/`NumberField` — see their own docs for details.
