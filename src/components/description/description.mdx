# Description

Supporting/help text for a form field, built on `react-aria-components`' `Text` with
`slot="description"`. It's automatically wired to the field's `aria-describedby` by React Aria, and
automatically hides itself while the field is invalid so it doesn't compete with the error message.

## Import

```tsx
import { Description } from '#src/components/description';
```

`TextField`, `NumberField`, `Checkbox`, and `CheckboxGroup` also re-export this as
`TextField.Description`, `NumberField.Description`, `Checkbox.Description`, and
`CheckboxGroup.Description` respectively, for convenience when composing those components.

## Usage

`Description` must be rendered inside a field root (for example `TextField` / `TextField.Root`)
— it reacts to the field's `invalid` state from that ancestor purely through styling, without
reading it from React context.

```tsx
import { useState } from 'react';

import { TextField } from '#src/components/text-field';

function Example() {
  const [value, setValue] = useState('');

  return (
    <TextField
      value={value}
      onChange={setValue}
    >
      <TextField.FieldContainer>
        <TextField.Label>{'Full name'}</TextField.Label>
        <TextField.Input placeholder="Jane Smith" />
      </TextField.FieldContainer>
      <TextField.Description>{'Used on your public profile.'}</TextField.Description>
    </TextField>
  );
}
```

## Behavior

- **Default**: small, field-foreground text below the field.
- **Invalid** (`isInvalid` on the field root): hidden, so `FieldError` can take its place without
  the two overlapping.
