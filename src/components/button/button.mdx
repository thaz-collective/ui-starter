# Button

A pressable button built on `react-aria-components`' `Button`. It covers seven color variants,
three sizes, an inverted (tinted) style, and an icon-only square mode, and responds to React
Aria's hover/press/focus-visible/disabled/pending states.

## Import

```tsx
import { Button } from '#src/components/button';
```

## Usage

```tsx
import { Button } from '#src/components/button';

function Example() {
  return <Button onPress={() => console.log('pressed')}>{'Save'}</Button>;
}
```

`ghost` and `outline` are transparent/bordered variants meant for lower-emphasis actions — both
stay transparent while disabled, rather than showing the default variants' dimmed background.

## Inverted

Setting `isInverted` swaps the solid background for a tinted one, keeping the variant's color as
the text color instead. Only `primary`, `secondary`,
`danger`, `success`, and `warning` define inverted styling — `ghost` and `outline` ignore the prop.

## Icon-only

Setting `isIcon` collapses the button to a square matching its `size`, removing the horizontal
padding and gap meant for text + icon combinations. Always pair it with `aria-label` since there's
no visible text for assistive technology to read.

## States

React Aria drives hover, press, and keyboard-focus styling automatically. `isDisabled` dims the
button and blocks interaction; `isPending` shows a pending/loading state, for use with async
`onPress` handlers.
