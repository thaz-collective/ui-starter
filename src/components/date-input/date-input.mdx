# DateInput

The segmented editable-date-part building block, built on `react-aria-components`' `DateInput`
and `DateSegment`. Each part of a date/time value (hour, minute, second, AM/PM, month, day, year,
etc.) renders as its own individually focusable segment rather than a single `<input>`. It's the
shared input primitive for date- and time-based fields, currently used by
[`TimeField`](/?path=/docs/component-timefield--docs).

## Import

```tsx
import { DateInput } from '#src/components/date-input';
```

`TimeField` also re-exports this as `TimeField.Input` for convenience when composing a time
field.

## Usage

`DateInput` must be rendered inside a date/time field root that provides React Aria's date-field
state (for example `TimeField` / `TimeField.Root`), typically inside a `FieldContainer`.

```tsx
import { useState } from 'react';

import { TimeField } from '#src/components/time-field';

function Example() {
  const [value, setValue] = useState<Temporal.PlainTime | null>(null);

  return (
    <TimeField
      value={value}
      onChange={setValue}
    >
      <TimeField.FieldContainer>
        <TimeField.Label>{'Meeting time'}</TimeField.Label>
        <TimeField.Input />
      </TimeField.FieldContainer>
    </TimeField>
  );
}
```

## Behavior

- **Segments**: renders one segment per editable part of the value (e.g. hour, minute, AM/PM) plus
  literal separators (e.g. `:`), each as its own focusable element — arrow keys and typing move
  between and edit segments individually.
- **Placeholder segments and literal separators fade in** once the field is focused or already has
  a real value, so an idle empty field reads as a single hint rather than a full template like
  `hh:mm AM`.
- **Focused segment**: highlighted so keyboard/pointer focus within the field is easy to track.
- **Disabled** (`isDisabled` on the field root): no longer interactive.
- **Read-only** (`isReadOnly` on the field root): focusable, but not editable.
- **Invalid** (`isInvalid` on the field root): takes error styling.
