# Label

A floating field label built on `react-aria-components`' `Label`. It sits over the input and
floats above it once the field is focused or has a value.

## Import

```tsx
import { Label } from '#src/components/label';
```

`TextField` also re-exports this as `TextField.Label` for convenience when composing a text field.

## Usage

`Label` must be rendered inside a `FieldContainer`-style wrapper, which itself must sit inside a
field root (for example `TextField` / `TextField.Root`). It reacts to state — focus, value,
required, invalid, disabled — from those ancestors, so it works with any field root that follows
the same conventions.

`Label` floats correctly whether its sibling is a plain `<input>` (`TextField`, `NumberField`) or
a segmented time input with no `<input>` element at all (`TimeField`).

```tsx
import { useState } from 'react';

import { TextField } from '#src/components/text-field';

function Example() {
  const [value, setValue] = useState('');

  return (
    <TextField
      value={value}
      onChange={setValue}
    >
      <TextField.FieldContainer>
        <TextField.Label>{'Full name'}</TextField.Label>
        <TextField.Input placeholder="Jane Smith" />
      </TextField.FieldContainer>
    </TextField>
  );
}
```

## Behavior

- **Idle**: centered over the input.
- **Focused / has value**: floats to the top of the container.
- **Required** (`isRequired` on the field root): appends a `*` after the label text.
- **Invalid** (`isInvalid` on the field root): takes error styling, taking precedence over the
  focused state's styling.
- **Disabled** (`isDisabled` on the field root): no longer interactive.
