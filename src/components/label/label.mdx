# Label

A floating field label built on `react-aria-components`' `Label`. It renders as plain text
positioned over the input and floats up on focus or value, driven entirely by CSS group
selectors — no local state.

## Import

```tsx
import { Label } from '#src/components/label';
```

`TextField` also re-exports this as `TextField.Label` for convenience when composing a text field.

## Usage

`Label` must be rendered inside a `FieldContainer`-style wrapper carrying the
`group/field-container` class, which itself must sit inside a field root carrying
`group/text-field` (for example `TextField` / `TextField.Root`). It reads state — focus, value,
required, invalid, disabled — from those ancestors via CSS `group-*` selectors, not React context,
so it works with any field root that follows the same group-naming convention.

```tsx
import { useState } from 'react';

import { TextField } from '#src/components/text-field';

function Example() {
  const [value, setValue] = useState('');

  return (
    <TextField
      value={value}
      onChange={setValue}
    >
      <TextField.FieldContainer>
        <TextField.Label>{'Full name'}</TextField.Label>
        <TextField.Input placeholder="Jane Smith" />
      </TextField.FieldContainer>
    </TextField>
  );
}
```

## Behavior

- **Idle**: centered vertically over the input, muted foreground color.
- **Focused / has value**: floats to the top of the container and shrinks to `text-xs`.
- **Required** (`isRequired` on the field root): appends a `*` after the label text.
- **Invalid** (`isInvalid` on the field root): text turns to the danger color; wins over the
  focused-primary color.
- **Disabled** (`isDisabled` on the field root): cursor becomes `not-allowed`.
