# FieldError

Validation error text for a form field, built on `react-aria-components`' `FieldError`. It reads
validation state directly from React Aria and only renders itself while the field is invalid.

## Import

```tsx
import { FieldError } from '#src/components/field-error';
```

`TextField` also re-exports this as `TextField.FieldError` for convenience when composing a text
field.

## Usage

`FieldError` must be rendered inside a field root that provides React Aria form-validation context
(for example `TextField` / `TextField.Root`) — unlike `Label` and `Description`, its visibility is
driven by React Aria itself rather than purely by styling, though its danger color still comes
from that same field root's invalid state.

```tsx
import { useState } from 'react';

import { TextField } from '#src/components/text-field';

function Example() {
  const [value, setValue] = useState('');

  return (
    <TextField
      value={value}
      onChange={setValue}
      isInvalid={true}
    >
      <TextField.FieldContainer>
        <TextField.Label>{'Email'}</TextField.Label>
        <TextField.Input placeholder="you@example.com" />
      </TextField.FieldContainer>
      <TextField.FieldError>{'Please enter a valid email address.'}</TextField.FieldError>
    </TextField>
  );
}
```

## Behavior

- **Valid**: not rendered (`hidden`).
- **Invalid** (`isInvalid` on the field root): shown, in the danger color.

`children` can also be a function of React Aria's validation result (e.g.
`{(validation) => validation.validationErrors.join(' ')}`) to surface native/custom validation
messages instead of a static string.
