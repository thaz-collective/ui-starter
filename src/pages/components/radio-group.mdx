# Radio Group

A single-selection radio group built on top of `react-aria-components`' `RadioGroup`, styled with
`tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { RadioGroup } from '#src/common/components/radio-group';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `RadioGroup`:

<pre>
  <code>{`RadioGroup
├── RadioGroup.Label (optional)
├── RadioGroup.Radio (one or more)
├── RadioGroup.Description (optional)
└── RadioGroup.FieldError (optional)`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

<table>
  <thead>
    <tr>
      <th>{'Component'}</th>
      <th>{'Description'}</th>
      <th>{'Optional'}</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>{'RadioGroup / RadioGroup.Root'}</td>
      <td>{'The container; supplies context to every slot below.'}</td>
      <td>{'No'}</td>
    </tr>
    <tr>
      <td>{'RadioGroup.Label'}</td>
      <td>{"The group's label text."}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'RadioGroup.Radio'}</td>
      <td>{'A single selectable radio option, rendered once per choice.'}</td>
      <td>{'No (at least one is required)'}</td>
    </tr>
    <tr>
      <td>{'RadioGroup.Description'}</td>
      <td>{'Supporting text under the group.'}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'RadioGroup.FieldError'}</td>
      <td>{'Validation error text, shown when isInvalid.'}</td>
      <td>{'Yes'}</td>
    </tr>
  </tbody>
</table>

Every slot must be rendered inside `RadioGroup`/`RadioGroup.Root` — they read shared context and
throw if used standalone. `RadioGroup.Root` accepts an `orientation` prop (`'vertical'` | `'horizontal'`,
default `'vertical'`) that lays out the radios and drives the container's flex direction.
