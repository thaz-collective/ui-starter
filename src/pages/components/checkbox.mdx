# Checkbox

A tri-state checkbox built on top of `react-aria-components`' `Checkbox`, with an optional
`Checkbox.Group` for managing a set of related checkboxes, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Checkbox } from '#src/common/components/checkbox';`}</code>
</pre>

<H2 id="composition">Composition</H2>

A single `Checkbox` renders standalone. To manage a set of related checkboxes, wrap them in
`Checkbox.Group`:

<pre>
  <code>{`Checkbox (standalone)

Checkbox.Group (optional, for multiple related checkboxes)
├── Checkbox.Label (optional)
├── Checkbox (one or more)
├── Checkbox.Description (optional)
└── Checkbox.FieldError (optional)`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

<table>
  <thead>
    <tr>
      <th>{'Component'}</th>
      <th>{'Description'}</th>
      <th>{'Optional'}</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>{'Checkbox / Checkbox.Root'}</td>
      <td>{'A single checkbox; renders its own box and check/indeterminate icon. Usable standalone.'}</td>
      <td>{'No'}</td>
    </tr>
    <tr>
      <td>{'Checkbox.Group'}</td>
      <td>{'Groups multiple checkboxes under one name/value; supplies context to the slots below.'}</td>
      <td>{'Yes (only needed for multi-checkbox groups)'}</td>
    </tr>
    <tr>
      <td>{'Checkbox.Label'}</td>
      <td>{"The group's label text. Requires Checkbox.Group context."}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'Checkbox.Description'}</td>
      <td>{'Supporting text under the group. Requires Checkbox.Group context.'}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'Checkbox.FieldError'}</td>
      <td>{'Validation error text, shown when the group is isInvalid. Requires Checkbox.Group context.'}</td>
      <td>{'Yes'}</td>
    </tr>
  </tbody>
</table>

`Checkbox.Label`, `Checkbox.Description`, and `Checkbox.FieldError` read `Checkbox.Group` context
and throw if rendered outside of it. A standalone `Checkbox` renders its own label as `children`.
