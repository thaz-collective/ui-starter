# Checkbox

An accessible checkbox built on top of `react-aria-components`' `Checkbox`, styled with `tailwind-variants`. Can be
used standalone or grouped with `Checkbox.Group`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Checkbox } from '#src/common/components/checkbox';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a standalone `Checkbox`:

<pre>
  <code>{`Checkbox (Checkbox.Field)
├── Checkbox.Button
└── Checkbox.FieldError (optional)`}</code>
</pre>

Or group multiple checkboxes under a shared label, description, and validation state:

<pre>
  <code>{`Checkbox.Group
├── Checkbox.GroupLabel (optional)
├── Checkbox.GroupDescription (optional)
├── Checkbox.GroupField (one or more)
│   └── Checkbox.Button
└── Checkbox.FieldError (optional)`}</code>
</pre>
