# Card

A compound container that composes `Surface` for its background, with slots for a
header, title, description, content, and footer.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Card } from '#src/common/components/card';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `Card`:

<pre>
  <code>{`Card
├── Card.Header (optional)
│   ├── Card.Title
│   └── Card.Description (optional)
├── Card.Content (optional)
└── Card.Footer (optional)`}</code>
</pre>

Each slot is a plain, self-contained element — none of them require a parent `Card` to
render, but they're styled to be composed together.

<H2 id="examples">Examples</H2>

<H3 id="nested-card">Nested card</H3>

Cards can be nested directly inside `Card.Content`. Stepping through
`default` → `secondary` → `tertiary` gives each layer a visibly distinct
background.

<Preview
  code={`<Card variant="default">
  <Card.Header>
    <Card.Title>Default</Card.Title>
    <Card.Description>Outermost card</Card.Description>
  </Card.Header>
  <Card.Content>
    <Card variant="secondary">
      <Card.Header>
        <Card.Title>Secondary</Card.Title>
        <Card.Description>Nested one level deep</Card.Description>
      </Card.Header>
      <Card.Content>
        <Card variant="tertiary">
          <Card.Header>
            <Card.Title>Tertiary</Card.Title>
            <Card.Description>Nested two levels deep</Card.Description>
          </Card.Header>
          <Card.Content>Innermost content.</Card.Content>
        </Card>
      </Card.Content>
    </Card>
  </Card.Content>
</Card>`}

</Preview>
