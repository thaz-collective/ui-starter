# Card

A compound container built on top of `Surface`, with slots for a header, title,
description, content, and footer.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Card } from '#src/common/components/card';`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

- `Card` / `Card.Root` — the container; supplies context to every slot below.
- `Card.Header` — top section, usually wraps `Title` and `Description`.
- `Card.Title` — the card's heading text.
- `Card.Description` — supporting text under the title.
- `Card.Content` — the main body.
- `Card.Footer` — bottom section, usually actions.

Every slot must be rendered inside `Card`/`Card.Root` — they read shared context and
throw if used standalone.
