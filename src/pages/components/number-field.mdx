# Number Field

A numeric input built on top of `react-aria-components`' `NumberField`, with increment
and decrement step buttons, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { NumberField } from '#src/common/components/number-field';`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

- `NumberField` / `NumberField.Root` — the container; supplies context to every slot below.
- `NumberField.LabelInputContainer` — wraps the label and input group.
- `NumberField.Label` — the field's label text.
- `NumberField.Group` — wraps the input and step buttons.
- `NumberField.Input` — the numeric input.
- `NumberField.StepButtons` — wraps the increment/decrement buttons.
- `NumberField.IncrementButton` — increments the value.
- `NumberField.DecrementButton` — decrements the value.
- `NumberField.Description` — supporting text under the field.
- `NumberField.FieldError` — validation error text, shown when `isInvalid`.

Every slot must be rendered inside `NumberField`/`NumberField.Root` — they read shared
context and throw if used standalone.
