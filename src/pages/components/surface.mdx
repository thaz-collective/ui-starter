# Surface

A single-slot background primitive that swaps between the app's layered surface colors.
`Card` builds on top of `Surface` for its non-transparent variants.

<pre>
  <code>{`import { Surface } from '#src/common/components/surface';`}</code>
</pre>

Each non-transparent variant also sets a `--field` CSS variable pointing at the next
deeper surface level, so form fields nested inside automatically pick up the right
background.
