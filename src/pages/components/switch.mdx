# Switch

A boolean toggle built on top of `react-aria-components`' `Switch`, styled with `tailwind-variants`.
Unlike most components in this library, `Switch` is not a compound component — it renders a single
element and its label as `children`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Switch } from '#src/common/components/switch';`}</code>
</pre>

<H2 id="composition">Composition</H2>

`Switch` is a single, standalone component — there is no compound API to assemble:

<pre>
  <code>{`Switch`}</code>
</pre>
