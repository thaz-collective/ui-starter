# Slider

A draggable-thumb range input built on top of `react-aria-components`' `Slider`, supporting
horizontal or vertical orientation and single- or multi-thumb ranges, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Slider } from '#src/common/components/slider';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `Slider`:

<pre>
  <code>{`Slider
├── Slider.Label (required, or pass aria-label/aria-labelledby instead)
├── Slider.Output (optional)
└── Slider.Track
    ├── Slider.FillTrack (optional)
    └── Slider.Thumb (one per thumb, positioned via its index prop)`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

<table>
  <thead>
    <tr>
      <th>{'Component'}</th>
      <th>{'Description'}</th>
      <th>{'Optional'}</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>{'Slider / Slider.Root'}</td>
      <td>{'The container; owns the slider state and orientation.'}</td>
      <td>{'No'}</td>
    </tr>
    <tr>
      <td>{'Slider.Label'}</td>
      <td>{"The slider's accessible label text."}</td>
      <td>{'No, unless aria-label or aria-labelledby is supplied on Slider.Root instead'}</td>
    </tr>
    <tr>
      <td>{'Slider.Output'}</td>
      <td>{'Displays the current value(s) as text.'}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'Slider.Track'}</td>
      <td>{'The draggable track; wraps FillTrack and every Thumb.'}</td>
      <td>{'No'}</td>
    </tr>
    <tr>
      <td>{'Slider.FillTrack'}</td>
      <td>{"The filled portion of the track up to the first thumb's position. Reads slider state directly, must be rendered inside Slider.Track."}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'Slider.Thumb'}</td>
      <td>{'A draggable thumb. Render one per value; each takes an index prop (0, 1, …) to build a multi-thumb range slider.'}</td>
      <td>{'No (at least one is required)'}</td>
    </tr>
  </tbody>
</table>

`Slider.Root` defaults `orientation` to `'horizontal'`. `Slider.FillTrack` only visualizes the fill up
to thumb `index={0}` — for multi-thumb ranges, omit it or provide a custom fill implementation.
RAC's `Slider` requires an accessible name: render `Slider.Label` as a child, or pass `aria-label`/
`aria-labelledby` directly on `Slider`/`Slider.Root` if a visible label isn't wanted.
