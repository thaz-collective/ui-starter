# List Box

A selectable list of items (single or multiple selection) built on top of
`react-aria-components`' `ListBox`, styled with `tailwind-variants`. This is the
shared collection primitive reused wherever a component needs an item/section/
header list — `Select`, `ComboBox`, and menu-style popover content.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { ListBox } from '#src/common/components/list-box';`}</code>
</pre>

<H2 id="composition">Composition</H2>

<pre>
  <code>{`ListBox
├── ListBox.Item
├── ListBox.Section (optional)
│   ├── ListBox.Header (optional)
│   └── ListBox.Item
└── ListBox.Collection (optional, for dynamic collections)`}</code>
</pre>
