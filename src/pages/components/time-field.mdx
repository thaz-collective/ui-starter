# Time Field

A time input built on top of `react-aria-components`' `TimeField`, where each part of the time
(hour, minute, second, AM/PM) is displayed as an individually editable segment, styled with
`tailwind-variants`. It reuses the same segmented `DateInput` building block as `DateField`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { TimeField } from '#src/common/components/time-field';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `TimeField`:

<pre>
  <code>{`TimeField
├── TimeField.LabelInputContainer (optional)
│   ├── TimeField.Label (optional)
│   └── TimeField.Input
├── TimeField.Description (optional)
└── TimeField.FieldError (optional)`}</code>
</pre>

Every slot must be rendered inside `TimeField`/`TimeField.Root` — they read shared context and
throw if used standalone.
