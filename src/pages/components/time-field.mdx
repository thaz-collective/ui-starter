# Time Field

A time input built on top of `react-aria-components`' `TimeFieldRoot`, where each part of the time
(hour, minute, second, AM/PM) is displayed as an individually editable segment, styled with
`tailwind-variants`. It reuses the same segmented `DateInput` building block as
[`DateTimePicker`](/components/date-time-picker).

Use `TimeFieldRoot` when you need a time value decoupled from any date — for a combined date and
time input, use `DateTimePicker` with a higher `granularity` instead.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { TimeField } from '#src/common/components/time-field';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `TimeFieldRoot`:

<pre>
  <code>{`TimeField
├── TimeField.LabelInputContainer (optional)
│   ├── TimeField.Label (optional)
│   └── TimeField.Input
├── TimeField.Description (optional)
└── TimeField.FieldError (optional)`}</code>
</pre>

throw if used standalone.
