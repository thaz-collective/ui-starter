# Table

A data table built on top of `react-aria-components`' `Table`, styled with
`tailwind-variants`. This page covers the base table primitive only — for sorting,
filtering, and pagination backed by `@tanstack/react-table`, see the data-table
integration separately.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Table } from '#src/common/components/table';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `Table`:

<pre>
  <code>{`Table
├── Table.TableHeader
│   └── Table.TableColumn (one per column)
└── Table.TableBody
    └── Table.TableRow (one per row)
        └── Table.TableDataCell (one per column)`}</code>
</pre>

      <td>{'Table.TableBody'}</td>
      <td>{'Wraps the rows.'}</td>
      <td>{'No'}</td>
    </tr>
    <tr>
      <td>{'Table.TableRow'}</td>
      <td>{'A single row.'}</td>
      <td>{'No'}</td>
    </tr>
    <tr>
      <td>{'Table.TableDataCell'}</td>
      <td>{'A single data cell.'}</td>
      <td>{'No'}</td>
    </tr>
  </tbody>
</table>

Each part is a plain, self-contained component — none of them require a parent `Table`
to render, but they're styled to be composed together.

<H3 id="selection">Selection</H3>

<Preview
  code={`export function TableWithSelectionExample() {
  const [selectedKeys, setSelectedKeys] = useState<Selection>(new Set());

return (

<Table
  aria-label="Team members"
  selectionMode="multiple"
  selectedKeys={selectedKeys}
  onSelectionChange={setSelectedKeys}
>
  <Table.TableHeader>
    <Table.TableColumn isRowHeader>Name</Table.TableColumn>
    <Table.TableColumn>Role</Table.TableColumn>
    <Table.TableColumn>Status</Table.TableColumn>
  </Table.TableHeader>
  <Table.TableBody items={rows}>
    {(row) => (
      <Table.TableRow>
        <Table.TableDataCell>{row.name}</Table.TableDataCell>
        <Table.TableDataCell>{row.role}</Table.TableDataCell>
        <Table.TableDataCell>{row.status}</Table.TableDataCell>
      </Table.TableRow>
    )}
  </Table.TableBody>
</Table>
);
}`}

>

  <TableWithSelectionExample />
</Preview>
