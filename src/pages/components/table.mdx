# Table

A plain, presentational data table — header, sortable/resizable columns, body,
rows, and cells — built on top of `react-aria-components`' `Table` primitives,
styled with `tailwind-variants`. This component has no data-modeling opinions
(no sorting/filtering/selection state); it's the styled markup layer that
`data-table` (the TanStack Table integration) renders into.

<H2 id="data-table">For data-driven tables</H2>

This component intentionally has no sorting/filtering/selection state — see
[Data Table](/components/data-table) for the TanStack Table v9 integration that
renders row/column models into these same `Table.*` parts.
