# Date Picker

A date picker combines a segmented `DateField` with a `Calendar` popover, letting users type a
date directly or pick one visually. Built on top of `react-aria-components`' `DatePicker`,
`Popover`, `Dialog`, and `Calendar`, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { DatePicker } from '#src/common/components/date-picker';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `DatePicker`:

<pre>
  <code>{`DatePicker
├── DatePicker.LabelInputContainer (optional)
│   ├── DatePicker.Label (optional)
│   └── DatePicker.Group
│       ├── DatePicker.Input
│       └── DatePicker.TriggerButton
├── DatePicker.Popover
│   └── DatePicker.Dialog
│       └── DatePicker.Calendar
├── DatePicker.Description (optional)
└── DatePicker.FieldError (optional)`}</code>
</pre>

throw if used standalone.
