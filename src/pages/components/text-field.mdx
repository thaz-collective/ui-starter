# Text Field

A single- or multi-line text input built on top of `react-aria-components`' `TextField`,
styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { TextField } from '#src/common/components/text-field';`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

- `TextField` / `TextField.Root` — the container; supplies context to every slot below.
- `TextField.LabelInputContainer` — wraps the label and input/textarea.
- `TextField.Label` — the field's label text.
- `TextField.Input` — a single-line text input.
- `TextField.TextArea` — a multi-line textarea (use instead of `Input`, not alongside it).
- `TextField.Description` — supporting text under the field.
- `TextField.FieldError` — validation error text, shown when `isInvalid`.

Every slot must be rendered inside `TextField`/`TextField.Root` — they read shared
context and throw if used standalone.
