# Text Field

A single- or multi-line text input built on top of `react-aria-components`' `TextField`,
styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { TextField } from '#src/common/components/text-field';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `TextField`:

<pre>
  <code>{`TextField
├── TextField.LabelInputContainer (optional)
│   ├── TextField.Label (optional)
│   └── TextField.Input (or TextField.TextArea)
├── TextField.Description (optional)
└── TextField.FieldError (optional)`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

<table>
  <thead>
    <tr>
      <th>{'Component'}</th>
      <th>{'Description'}</th>
      <th>{'Optional'}</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>{'TextField / TextField.Root'}</td>
      <td>{'The container; supplies context to every slot below.'}</td>
      <td>{'No'}</td>
    </tr>
    <tr>
      <td>{'TextField.LabelInputContainer'}</td>
      <td>{'Wraps the label and input/textarea.'}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'TextField.Label'}</td>
      <td>{"The field's label text."}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'TextField.Input'}</td>
      <td>{'A single-line text input.'}</td>
      <td>{'No (use instead of TextArea, not alongside it)'}</td>
    </tr>
    <tr>
      <td>{'TextField.TextArea'}</td>
      <td>{'A multi-line textarea.'}</td>
      <td>{'No (use instead of Input, not alongside it)'}</td>
    </tr>
    <tr>
      <td>{'TextField.Description'}</td>
      <td>{'Supporting text under the field.'}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'TextField.FieldError'}</td>
      <td>{'Validation error text, shown when isInvalid.'}</td>
      <td>{'Yes'}</td>
    </tr>
  </tbody>
</table>

Every slot must be rendered inside `TextField`/`TextField.Root` — they read shared
context and throw if used standalone.
