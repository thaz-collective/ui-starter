# Tag Group

A collection of tags built on top of `react-aria-components`' `TagGroup`, supporting selection and
removable tags, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { TagGroup } from '#src/common/components/tag-group';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `TagGroup`:

<pre>
  <code>{`TagGroup
├── TagGroup.Label (optional)
├── TagGroup.List
│   └── TagGroup.Tag (one or more)
├── TagGroup.Description (optional)
└── TagGroup.FieldError (optional)`}</code>
</pre>

Every slot must be rendered inside `TagGroup`/`TagGroup.Root` — they read shared context and throw
if used standalone. Pass `selectionMode="single"` or `"multiple"` on `TagGroup.List` to make tags
selectable; a tag renders differently (solid vs. secondary styling) depending on whether it's
selected. Pass `onRemove` on `TagGroup.List` and `allowsRemoving` is derived automatically — each
`TagGroup.Tag` then renders a remove button.

`TagGroup.Root` mainly forwards layout/validation props; selection (`selectionMode`,
`selectedKeys`/`defaultSelectedKeys`, `onSelectionChange`) and removal (`onRemove`) are configured on
`TagGroup.List`, matching RAC's own `TagGroup`/`TagList` split.
