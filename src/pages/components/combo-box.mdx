# Combo Box

An editable, filterable dropdown built on top of `react-aria-components`' `ComboBox`, combining a
text input with a popover listbox, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { ComboBox } from '#src/common/components/combo-box';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `ComboBox`:

<pre>
  <code>{`ComboBox
├── ComboBox.Label (optional)
├── ComboBox.Group
│   ├── ComboBox.Input
│   └── ComboBox.TriggerButton (optional)
├── ComboBox.Popover
│   └── ComboBox.ListBox
│       ├── ComboBox.Item (one or more)
│       └── ComboBox.Section (optional, groups items)
│           ├── ComboBox.Header (optional)
│           ├── ComboBox.Collection (optional, for dynamic items)
│           └── ComboBox.Item (one or more)
├── ComboBox.Description (optional)
└── ComboBox.FieldError (optional)`}</code>
</pre>

Every slot must be rendered inside `ComboBox`/`ComboBox.Root` — they read shared context and throw
if used standalone. Selection is controlled via RAC's classic `selectedKey`/`onSelectionChange` API,
separate from the free-typed `inputValue`/`onInputChange`.
