# Search Field

A single-line search input built on top of `react-aria-components`' `SearchField`, with a leading
search icon and a clear button, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { SearchField } from '#src/common/components/search-field';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `SearchField`:

<pre>
  <code>{`SearchField
├── SearchField.Label (optional)
├── SearchField.Group
│   ├── SearchField.Input
│   └── SearchField.ClearButton (optional)
├── SearchField.Description (optional)
└── SearchField.FieldError (optional)`}</code>
</pre>

throw if used standalone.
