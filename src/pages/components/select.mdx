# Select

A listbox-style dropdown select built on top of `react-aria-components`' `Select`, with a popover
listbox and support for sections, styled with `tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Select } from '#src/common/components/select';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `Select`:

<pre>
  <code>{`Select
├── Select.Label (optional)
├── Select.Trigger
│   └── Select.Value
├── Select.Popover
│   └── Select.ListBox
│       ├── Select.Item (one or more)
│       └── Select.Section (optional, groups items)
│           ├── Select.Header (optional)
│           ├── Select.Collection (optional, for dynamic items)
│           └── Select.Item (one or more)
├── Select.Description (optional)
└── Select.FieldError (optional)`}</code>
</pre>

Every slot must be rendered inside `Select`/`Select.Root` — they read shared context and throw if
used standalone. Selection is controlled via RAC's classic `selectedKey`/`onSelectionChange` API.
