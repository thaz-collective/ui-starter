# Select

An accessible dropdown built on top of `react-aria-components`' `Select`, styled with `tailwind-variants`. Supports
single or multiple selection, and an optional autocomplete search field.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Select } from '#src/common/components/select';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `Select`:

<pre>
  <code>{`Select
├── Select.TriggerGroup
│   ├── Select.LabelValueContainer
│   │   ├── Select.Label
│   │   └── Select.Value
│   │       └── Select.Tags (rendered when selectionMode is "multiple" and items are selected)
│   ├── Select.ClearButton (rendered when a value is selected)
│   └── Select.TriggerButton
│       └── Select.Chevron
├── Select.Description (optional)
├── Select.FieldError (optional)
└── Select.Popover
    ├── Select.Autocomplete (optional)
    │   ├── Select.SearchField
    │   │   └── Select.SearchInput
    │   └── Select.ListBox
    │       ├── Select.Item
    │       └── Select.Section (optional)
    │           ├── Select.Header
    │           └── Select.Item
    └── Select.ListBox (when not using Autocomplete)
        ├── Select.Item
        └── Select.Section (optional)
            ├── Select.Header
            └── Select.Item`}</code>
</pre>

<H2 id="examples">Examples</H2>

`Select.TriggerGroup` is a `Group`, not a `Button` — this lets `Select.ClearButton` and, in multiple-selection mode,
each tag's remove button be real, independently-clickable buttons instead of being nested inside another button
(which is invalid HTML). `Select.TriggerGroup` and `Select.Popover` share the trigger element's ref internally, so
`Select.Popover` still anchors and sizes itself to the field automatically — no `ref` wiring required.

<H3 id="multiple-selection">Multiple selection</H3>

Set `selectionMode="multiple"` to allow selecting more than one option. `value` and `onChange` then work with an
array of keys instead of a single key. Selected options render as removable tag pills via `Select.Tags`.

<Preview
  code={`<Select selectionMode="multiple" placeholder="Select fruits">
  <Select.TriggerGroup>
    <Select.LabelValueContainer>
      <Select.Label>Favorite fruits</Select.Label>
      <Select.Value />
    </Select.LabelValueContainer>
    <Select.ClearButton />
    <Select.TriggerButton>
      <Select.Chevron />
    </Select.TriggerButton>
  </Select.TriggerGroup>
  <Select.Popover>
    <Select.ListBox>
      <Select.Item id="apple">Apple</Select.Item>
      <Select.Item id="banana">Banana</Select.Item>
      <Select.Item id="cherry">Cherry</Select.Item>
      <Select.Item id="grape">Grape</Select.Item>
    </Select.ListBox>
  </Select.Popover>
</Select>`}
>
  <SelectWithMultipleSelectionExample />
</Preview>

<H3 id="autocomplete">Autocomplete</H3>

Wrap `Select.ListBox` in `Select.Autocomplete` and add a `Select.SearchField` with a `Select.SearchInput` to let
users filter the options by typing.

<Preview
  code={`<Select placeholder="Select a fruit">
  <Select.TriggerGroup>
    <Select.LabelValueContainer>
      <Select.Label>Favorite fruit</Select.Label>
      <Select.Value />
    </Select.LabelValueContainer>
    <Select.ClearButton />
    <Select.TriggerButton>
      <Select.Chevron />
    </Select.TriggerButton>
  </Select.TriggerGroup>
  <Select.Popover className="flex flex-col">
    <Select.Autocomplete>
      <Select.SearchField aria-label="Search fruits">
        <Select.SearchInput placeholder="Search fruits" autoFocus />
      </Select.SearchField>
      <Select.ListBox>
        <Select.Item id="apple">Apple</Select.Item>
        <Select.Item id="banana">Banana</Select.Item>
        <Select.Item id="cherry">Cherry</Select.Item>
        <Select.Item id="grape">Grape</Select.Item>
      </Select.ListBox>
    </Select.Autocomplete>
  </Select.Popover>
</Select>`}
>
  <SelectWithAutocompleteExample />
</Preview>
