# Select

An accessible single-select dropdown built on top of `react-aria-components`' `Select`, styled with
`tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { Select } from '#src/common/components/select';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `Select`:

<pre>
  <code>{`Select
├── Select.Trigger
│   ├── Select.Label
│   └── Select.Value
├── Select.Description (optional)
├── Select.FieldError (optional)
└── Select.Popover
    └── Select.ListBox
        ├── Select.Item
        └── Select.Section (optional)
            ├── Select.Header
            └── Select.Item`}</code>
</pre>
