# Date Field

A date/time input built on top of `react-aria-components`' `DateField`, where each part of the
date (month, day, year, etc.) is displayed as an individually editable segment, styled with
`tailwind-variants`.

<H2 id="import">Import</H2>

<pre>
  <code>{`import { DateField } from '#src/common/components/date-field';`}</code>
</pre>

<H2 id="composition">Composition</H2>

Use the following composition to build a `DateField`:

<pre>
  <code>{`DateField
├── DateField.LabelInputContainer (optional)
│   ├── DateField.Label (optional)
│   └── DateField.Input
├── DateField.Description (optional)
└── DateField.FieldError (optional)`}</code>
</pre>

<H2 id="anatomy">Anatomy</H2>

<table>

    </tr>

      <td>{'Supporting text under the field.'}</td>
      <td>{'Yes'}</td>
    </tr>
    <tr>
      <td>{'DateField.FieldError'}</td>
      <td>{'Validation error text, shown when isInvalid.'}</td>
      <td>{'Yes'}</td>
    </tr>
  </tbody>
</table>

Every slot must be rendered inside `DateField`/`DateField.Root` — they read shared context and
throw if used standalone.
